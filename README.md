# vscode-cybersecurity-toolkit
A cybersecurity project using VS Code and Python to create a security log analyzer that counts failed login attempts and flags accounts for further investigation.

**Tool Name:** Visual Studio Code (VS Code)
**Author Name:** Alexandra LeNoir

## Tool Purpose
VS Code is a free code editor used to write, run, and debug programs. For this project, I used VS Code and Python to create a security log analyzer that counts failed login attempts and warns when an account has three or more failures.

## Installation Instructions
1. Download VS Code: https://code.visualstudio.com/
2. Install Python: https://www.python.org/downloads/
3. Open VS Code and install the Python extension by Microsoft.
4. Open the project folder containing the Python script.

## Basic Usage Instructions
1. Open 'security_log_analyser.py'.
2. Open Terminal > New Terminal.
3. Run 'py security log analyzer.py'.
4. Review the results in the terminal.
5. Change a sample login result, save the file, and run it again to compare results.

The program uses sample data and does not access real login records.
